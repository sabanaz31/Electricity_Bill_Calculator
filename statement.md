## Project Statement

The Electricity Bill Calculator is a simple Python-based application developed to calculate an electricity bill from the number of units consumed by a customer.

The project was created as a basic academic application to understand how Python classes and modules can be used together in a small real-world type of problem. The user enters the customer name, customer ID, and units consumed. The program then calculates the energy charge using predefined unit slabs, adds a fixed charge, and displays the final bill.

The project uses five main classes:

1. `Customer`
2. `Units`
3. `EnergyCharge`
4. `FixedCharge`
5. `Bill`

The `main.py` file connects these classes and controls the flow of the program.

The project deliberately avoids unnecessary complexity such as databases, payment gateways, login systems, and graphical interfaces. The main focus is on Python fundamentals, modular programming, and a clear calculation process.

## Objectives

1. To create a simple electricity bill calculation program using Python.
2. To practice classes and objects.
3. To understand how separate Python modules can work together.
4. To apply conditional statements to slab-based calculations.
5. To produce a clear and readable electricity bill as output.

## Scope

The current project is designed for academic and demonstration purposes. It can calculate a bill for one customer at a time using the predefined sample rates.

The project can later be expanded with features such as input validation, file storage, a graphical interface, multiple customer records, and configurable tariff rates.

## Expected Outcome
